# data/

The CSVs in this directory are not committed — the two raw Atlas tables are 24 MB
and 33 MB, and `analysis_sample.csv` is another 29 MB. All three are reproduced by
running the notebooks in order.

| File | How to get it |
|---|---|
| `tract_outcomes_simple.csv` | Downloaded by [`../code/00_pull.ipynb`](../code/00_pull.ipynb) from [Opportunity Insights](https://opportunityinsights.org/wp-content/uploads/2018/10/tract_outcomes_simple.csv) (Atlas table 4) |
| `tract_covariates.csv` | Downloaded by [`../code/00_pull.ipynb`](../code/00_pull.ipynb) from [Opportunity Insights](https://opportunityinsights.org/wp-content/uploads/2018/10/tract_covariates.csv) (Atlas table 9) |
| `analysis_sample.csv` | Written by [`../code/01_merge.ipynb`](../code/01_merge.ipynb) |

Data library and codebooks: <https://opportunityinsights.org/data/>
